# 数据看板

CWD 内置提供评论数据分析和访客数据分析功能。

## 评论数据分析

评论数据分析功能包含：

- 总评论数统计
- 最近 30 天评论数据可视化图表
- 按站点分类查看评论数据

## 访客数据分析

访客数据分析功能包含：

### 概览数据

- 总访问量（PV）统计
- 总页面数统计
- 今日访问量
- 昨日访问量
- 本周访问量
- 上周访问量（用于同比对比）
- 本月访问量
- 上月访问量（用于同比对比）
- 最近 30 天访客数据可视化图表

### 访问明细

- 页面访问明细，支持按 PV 排序或查看最新访问记录
- 点赞页面访问记录

访问明细和点赞排行的「页面地址」用于打开文章，不是统计的存储键。对于 `https://raclen.top` 已登记的旧文章地址，后台直接显示并打开 `/blog/编号/`，无需再次访问文章来刷新旧记录。其他站点及未登记的网页地址不做重写。点赞记录只有相对路径、没有完整网页地址时，只显示文本，不会误打开后台自身的路径。

短链接映射位于 `cwd-admin/src/views/AnalyticsVisitView/pageRedirects.json`，来自博客 `raclen/zone` 的 `public/_redirects`，按来源和旧路径精确匹配。只有新增或变更旧地址重定向时才需要同步此表；直接使用编号发布的新文章不需要登记。这里的映射不改动评论、点赞、PV 或博客本身的 301 规则。

### 数据分析

- 同比趋势：对比本周与上周、本月与上月的访问量变化
- 趋势图表：通过可视化图表直观展示访问数据的变化趋势

## 站点筛选

管理后台顶部导航栏提供了全局站点下拉选择器，用于在多站点之间切换数据视图。

在数据看板页面，所有数据统计都会根据选中的站点进行筛选，确保您能准确查看每个站点的数据情况。
